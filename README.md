## 使用方式

对AI说：**"帮我安装J5C22FM里的XXskill"**，AI会自动读取对应目录的说明，帮你下载并安装。

### 安装闪卡到桌面

对AI说：**"帮我安装github上的J5C22FM中的闪卡这个skill并放到桌面上"**，AI会：
1. 从本仓库 [闪卡](./闪卡) 目录下载 skill 完整内容
2. 解压到桌面，文件夹名为「闪卡」
3. 打开 SKILL.md 查看使用说明即可

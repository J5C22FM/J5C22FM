# PUBG Optimizer（PUBG 一键优化工具）

适用于 Windows 10 / Windows 11（64 位）的 PUBG 性能优化脚本，**自动检测硬件配置、按需适配、全程可一键还原**。

## 功能特性

运行一次自动完成 8 项优化/检查：

| # | 项目 | 说明 |
|---|------|------|
| 1 | 电源计划 | 切换为「高性能」计划（已是则不重复切换） |
| 2 | 关闭全屏优化 | 自动定位 PUBG 的 TslGame.exe，关闭系统全屏优化干扰 |
| 3 | 关闭 Xbox Game Bar | 关闭后台录制与自动游戏模式，减少后台占用 |
| 4 | 清理临时文件 | 清理用户/系统临时文件与预读取，带路径安全保护 |
| 5 | 虚拟内存 | 按**物理内存 1.5 倍**自动计算设置（不写死数值） |
| 6 | 网络优化 | 关闭 Nagle 算法，降低网络延迟 |
| 7 | 防自动重启 | 防止 Windows 更新在游戏时自动重启 |
| 8 | 驱动检查 | 检测 NVIDIA 驱动版本/日期，过旧时提示并可选打开官方下载页 |

## 使用方法

1. 下载本仓库，解压后右键 `PUBG_Optimize.bat` → **以管理员身份运行**
2. 脚本自动检测权限（非管理员自动提权），弹窗确认后开始优化
3. 全程输出中文日志，每步做了什么一目了然
4. 完成后**重启电脑**使虚拟内存、网络参数完全生效

### 一键还原

运行同目录下的 `Restore_PUBG.bat`，自动读取优化时生成的备份文件（`PUBG_Backup.ini`），恢复全部原始设置。

## 为什么是"通用自适应"？

脚本不写死任何硬件数值，运行时自动读取当前电脑：

- **内存**：自动检测物理内存大小，虚拟内存按 1.5 倍计算（8GB → 12GB、16GB → 24GB、32GB → 48GB …）
- **显卡**：自动识别 NVIDIA / AMD / Intel，NVIDIA 额外执行驱动检查
- **游戏路径**：自动从注册表定位 Steam 安装目录，找不到则安全跳过

所以任何电脑下载后都能直接用，不需要改任何参数。

## 安全性设计

- 所有修改**开始前弹窗确认**，未确认不执行
- 修改前自动备份原始设置到 `PUBG_Backup.ini`
- 清理临时文件前对路径做**非空 / 根目录 / 盘符根校验**，异常时自动保护跳过
- 提供 `Restore_PUBG.bat` 一键还原全部修改
- 脚本只做注册表与系统设置级优化，**不包含任何文件删除之外的危险操作**

## 支持环境

- Windows 10 / Windows 11（64 位）
- 需要管理员权限（脚本自动提权）
- PUBG（Steam 版）

## 常见问题

**Q：运行后需要重启吗？**
A：建议重启。虚拟内存和网络参数的修改需要重启后完全生效。

**Q：我的游戏装在别的盘，脚本找不到怎么办？**
A：脚本通过 Steam 注册表定位，一般都能找到；找不到会提示跳过，不影响其余优化项。

**Q：闪退/黑屏/掉帧还有什么要排查？**
A：优先做三件事：① 更新显卡驱动到最新 Game Ready 版；② 排查串流类软件安装的虚拟显示器驱动（如 GameViewer）并卸载；③ 确认 PUBG 装在 SSD 而不是机械盘。

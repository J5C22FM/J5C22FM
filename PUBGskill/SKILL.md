# PUBG 优化技能（PUBG Optimize）

## 功能

运行一次自动完成 8 项优化/检查，全程中文日志、可一键还原：

1. 电源计划切换为「高性能」
2. 关闭 PUBG 全屏优化干扰（自动定位 TslGame.exe）
3. 关闭 Xbox Game Bar 后台录制
4. 清理临时文件与预读取（带路径安全保护）
5. 虚拟内存按物理内存 1.5 倍自动计算设置
6. 网络延迟优化（关闭 Nagle 算法）
7. 防止 Windows 更新在游戏时自动重启
8. 显卡驱动检查（NVIDIA 过旧时提示更新）

## 使用方式

### 方式一：直接运行脚本（推荐给玩家）

1. 解压本 skill 目录，右键 `PUBG_Optimize.bat` → **以管理员身份运行**
2. 脚本自动检测电脑配置（内存、显卡、Steam 路径），弹窗确认后开始优化
3. 完成后重启电脑生效

### 方式二：让 AI 分析并生成方案

把以下指令发给 AI（配合本 skill）：

```
请根据我的电脑配置分析 PUBG 闪退/掉帧原因，并生成安全的优化 bat 脚本
```

AI 应按本技能的标准流程：先读取电脑配置（CPU/显卡/内存/电源计划/虚拟内存）→ 归因分析 → 生成通用自适应优化脚本 → 提供一键还原方案。

## 通用自适应设计

- 脚本不写死硬件数值，运行时自动检测物理内存、显卡品牌（NVIDIA/AMD/Intel）、Steam 安装路径
- 任何 Windows 10/11 64 位电脑下载后都能直接使用

## 安全与还原

- 所有修改开始前弹窗确认
- 修改前自动备份原始设置到 `PUBG_Backup.ini`
- 清理路径带非空/根目录/盘符根校验，异常自动保护跳过
- 运行 `Restore_PUBG.bat` 可一键还原全部修改

## 常见问题排查指引

1. **闪退/黑屏**：优先更新显卡驱动到最新 Game Ready 版；排查串流类软件（如 GameViewer）虚拟显示器驱动并卸载
2. **掉帧/low帧**：确认游戏装在 SSD；关闭后台录制
3. **黑屏重启**：检查电源功率与散热；内存 XMP 不稳时先恢复默认频率
